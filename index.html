온라인 판매 관리

판매 상품의 온라인 공개를 관리합니다. 무료 나눔과 렌탈은 별도 메뉴에서 관리합니다.

공개상품 선택

0개 공개
전체 시트의 상품을 표시합니다. 공개 설정 후 상단 중앙 동기화가 완료되어야 쇼핑몰에 반영됩니다. 쇼핑몰 연동 SQL 설치가 필요합니다.
판매 유형과 입금계좌는 각 상품의 '온라인 설정'에서 입력하세요. 연동설정 SQL을 실행하면 온라인 공개상품이 주문 페이지에 자동 반영됩니다. 주문 알림은 「온라인 주문·렌탈」 메뉴에서 확인하세요.
0개 선택
판매상품 관리
스크롤 위치와 관계없이 아래 버튼으로 바로 처리하세요.

무료 나눔 관리

무료 나눔 상품의 공개 상태와 재고를 별도로 관리합니다.

나눔 상품 현황

0개 무료 나눔 상품
상품 수정 화면에서 온라인 상품 유형을 '무료 나눔상품'으로 설정하면 여기에 표시됩니다. 공개 설정은 기존 Supabase 저장 기능을 이용합니다.
0개 선택

0개 렌탈 상품
